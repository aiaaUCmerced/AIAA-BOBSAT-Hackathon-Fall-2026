Bobcat Ballistics requires the contracted team to produce a basic flight software simulation using NASA/JPL's F´ framework to demonstrate the satellite's ability to execute commands, generate telemetry, report system events, and transition between operational flight software modes.

---

For this deliverable, the analysts shall deliver the following:

1. A basic F´ deployment demonstrating the creation, integration, and execution of a custom F´ component. The deployment should be operable through the F´ Ground Data System and demonstrate successful command execution.
    
2. A telemetry demonstration using F´ components, ports, commands, events, and telemetry channels. The analysts should demonstrate communication between components and show telemetry being generated and displayed through the F´ Ground Data System.
    
3. A simple spacecraft flight software mode manager demonstrating transitions between at least three operational modes, such as SAFE, NOMINAL, and SCIENCE. Mode changes should generate an observable event and telemetry indicating the spacecraft's current mode.

---

For further consideration, the analysts should deliver the following:

1. A more complete spacecraft mode management system including additional modes such as DOWNLINK, DETUMBLE, or PAYLOAD OPERATIONS, with transitions driven by spacecraft conditions rather than only ground commands.
    
2. A flight software simulation where spacecraft telemetry values such as battery state, attitude, payload status, or communications status influence F´ mode transitions and component behavior.
    
3. An interface between F´ and a spacecraft dynamics simulator such as Basilisk, allowing F´ to receive simulated spacecraft states and issue commands that modify spacecraft behavior.
    
4. A demonstration of flight software modes controlling simulated spacecraft behavior. For example, SAFE mode may command Sun-pointing, NOMINAL mode may command nadir-pointing, SCIENCE mode may command target-pointing, and DOWNLINK mode may command ground-station-pointing.

---

Bobcat Ballistics is providing the following resources for the analysts' reference:

[F´ Hello World Tutorial](https://fprime.jpl.nasa.gov/latest/tutorials-hello-world/docs/hello-world/): This tutorial introduces the basic F´ development workflow, including creating an F´ project, developing a component, integrating it into a deployment, building the software, and interacting with the deployment through the F´ Ground Data System. See this first!

[F´ Math Component Tutorial](https://fprime.jpl.nasa.gov/latest/tutorials-math-component/docs/math-component/#creating-components-part-1-creating-the-mathsender): After understanding the basic F´ workflow, use this tutorial to learn how components communicate through ports and how F´ implements commands, events, telemetry channels, custom data types, and connected components. This tutorial should serve as the primary reference for the telemetry demonstration.

[F´ Cheat Sheet](https://fprime.jpl.nasa.gov/cheatsheet.pdf): This document provides a quick reference for commonly used F´ concepts, commands, component definitions, ports, telemetry, events, deployments, and Ground Data System operations. Keep this available while developing the F´ simulation.

[Basilisk Flight Software Mode Example](https://hanspeterschaub.info/basilisk/examples/scenarioRendezVous.html): This example demonstrates the conceptual use of different flight software modes within a spacecraft simulation. After completing the basic F´ deliverables, use this example to explore how F´ operational modes could eventually control spacecraft behavior within a Basilisk simulation.
