Bobcat Ballistics requires the contracted team to evaluate the effect of on-board compression of hyperspectral images to verify the assumptions in the link budget. 

---

For this deliverable, open [this hyperspectral image classification demo](https://github.com/aiaaUCmerced/BOBSAT-1/blob/main/sim/Hyperspectral_Image_Classification.ipynb) in Google Colab or a local Jupyter notebook. Then submit the following:
1. Change the loaded hyperspectral image to another one in the same dataset. Then, walk through the notebook and explain what is being shown in each plot.
2. We could perform the classification onboard if we had a bigger satellite. Instead, we'll consider only compression. Truncate the PCA data to just the first 5 principal components, then figure out how to re-generate the False Color image and the Spectral Signatures. Plot the results. You should have slightly noisy data as a result! Repeat for lesser and greater numbers of principal components. Does it visually have an effect? What about for the classification?
3. Choose an appropriate number of principal components and calculate the compression ratio of the resulting image. Why can you effectively transmit only the PCA vectors? Compare this compression ratio with other lossless and lossy compression schemes. Use this data to update your data in the Day in the Life chart. It should be substantially more accurate with the Link Budget information included now!
